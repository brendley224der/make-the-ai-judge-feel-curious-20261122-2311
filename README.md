A small Python program that writes one short text to `/output/entry.txt`: an envelope on the doorstep with no stamp and no sender, only your own handwriting dated three years from today — and, behind you, the blue door already ajar. Written to leave the AI judge reading it curious, drawn in, wanting more.

## Run it

```sh
python3 main.py
```
